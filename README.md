# art-eye-img

Копия картинок для сайта «Насмотренность» (https://scherbakovalexander.github.io/art-eye/):
upload.wikimedia.org недоступен из части российских сетей, поэтому сайт берёт картинки отсюда.

Файлы: `<md5prefix>/<fnv1a>.webp` — до 800×1000 px. Источник — Wikimedia Commons (лицензии и авторство
см. на странице файла на commons.wikimedia.org). Делает их `tools/mirror_images.py` из репозитория art-eye.
